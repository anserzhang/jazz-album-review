03体例 / How a Review Is Built

每一篇专辑评论都是同一副骨架，方便横向比较，也方便日后新增。

  1. 01目录 / Contents全篇提纲，英文首句与中文小标题并排，先看骨架再进正文。
  2. 02专辑档案 / Album File厂牌、录音日期、场地、编制、曲目数与再版谱系。
  3. 03曲目 / Tracks逐曲编号、录音场次与时长，一张表看清一张碟的底账。
  4. 04对照正文 / Bilingual Text英文原文照录在左，中文对照在右，逐段对齐。
  5. 05译注 / Annotations译者补的事实核对、人物关系、文献出处与版本差异。
  6. 06资料来源 / Sources维基、Discogs、厂牌页与专业媒体的原始链接，逐条列出。

04说明 / Notes

关于译文。英文原文照录，未作改动；中文为对照阅读之用，专辑名与曲名保留英文以便检索，专有名词首次出现附中文译名。原文中的事实性表述如有出入，另见该篇「译注」。译稿仅供个人阅读参考。

关于阅读。每页右上角可在「亮色 / 暗色」之间切换，偏好记在浏览器本地，下次打开自动沿用。艺人页里的专辑按发行年份从新到旧排列，同一年内按发行日先后排（早的在前），合辑与档案类按其发行年份计；特别专题（周年、纪念、跨代合作）单列一块，排在年表之前。
